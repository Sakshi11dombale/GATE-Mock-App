## **GATE MockTest App 📱** 

A full-featured Android application for GATE (Graduate Aptitude Test in Engineering) exam preparation. Built with Java and Android SDK, the app provides real Previous Year Questions (PYQs), topic-wise tests, full mock tests, branch-specific content, and a detailed student dashboard — exactly like a real GATE test platform.

## ✨ **Features**

#### 🔐 **Authentication**


User Registration with name, email, username, password

Branch selection during signup (CSE / ECE / ME / CE / EE / IN / CH / BT)

GATE target year selection

Secure Login with username and password

Persistent login session using Room database

Logout from the profile screen


#### 📚 **Branch-wise Content**


Questions, topics, and tests are automatically filtered based on the user's selected branch

All 5 major GATE branches supported: CSE, ECE, ME, CE, EE

General Aptitude questions included for all branches


#### 📝 **Test Modes**


Full Mock Test — 30 questions, 1 hour, negative marking

Topic-wise Test — Practice individual subjects (Algorithms, DBMS, Networks, Thermodynamics, etc.)

PYQ Mode — Year-wise Previous Year Questions (2021–2024) filtered by branch



#### ⏱️ **Real Exam Experience**


Live countdown timer with color change in last 10 minutes

Question navigation palette (colour-coded: answered, marked, not visited)

Mark for review functionality

Clear answer option

GATE-style negative marking (−1/3 for 1-mark, −2/3 for 2-mark)

Submit confirmation dialog with attempt summary


#### 📊 **Results & Analytics**


Detailed score card with marks, percentage, and grade

Correct / Wrong / Not Attempted breakdown

Time taken display

Estimated GATE rank

Accuracy percentage

Share result with friends


#### 👤 **Student Dashboard**


Profile card with name, branch, and target year

Total tests taken, average accuracy, study time, questions solved

Weak area tracker with progress bars

Test history with scores


#### ➕ **Add Questions (Admin)**


Built-in screen to add new questions directly inside the app

Select subject, branch, difficulty, marks, correct answer

Mark as PYQ with year, or as mock question

Questions saved instantly to local database
