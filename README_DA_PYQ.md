# DA Previous-Year Papers

The DA PYQ screen discovers years directly from:

app/src/main/assets/questions/DA/PYQ/

Included files:
- DA_2024.json
- DA_2025.json

Each file is loaded independently, so selecting GATE 2024 PYQ loads only DA_2024.json and selecting GATE 2025 PYQ loads only DA_2025.json.
